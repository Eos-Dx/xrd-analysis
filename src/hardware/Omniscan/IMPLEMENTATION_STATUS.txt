    ├─→ Click "Init Detector" button
    │
    ├─→ API Call: POST /api/hardware/detector/init

    │
    ├─→ Orchestrator REST Server
    │   ├─ Verify enable button active (20s window)
    │   ├─ Check all safety interlocks
    │   └─ Call gRPC to hardware server
    │
    ├─→ Hardware Server (Rust)
    │   └─ Initialize detector
    │
    ├─→ Backend broadcasts WebSocket event
    │   (type: 'hardware_init', device: 'detector', ...)
    │
    ├─→ UI receives WebSocket event
    │   ├─ Show green notification
    │   ├─ Call api.getSystemState()
    │   └─ Update store with new state
    │
    └─→ Hardware Status panel updates automatically

Total time to notification: 2.6-5.6 seconds

  ✓ Power = OK (PDU providing power)
  ✓ Door = Any state (open or closed doesn't matter)

  • No enable button required
  • No interlocks required
  • Can be run anytime
  • Immediate shutdown
